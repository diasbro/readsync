# readsync

Читалка, в которой текст книги идёт вровень с аудиокнигой: пока чтец говорит, на экране
подсвечивается текущее предложение и слово. Сделана для тренировки внимания: читать глазами
и слушать одновременно, без отвлечений. Работает локально, в браузере, без аккаунтов.

*readsync is a local immersion-reading app: the book text follows the audiobook with
sentence and word highlighting. The interface, docs and text heuristics are Russian-first
(chapter detection, sentence splitting, transliterated slugs); the pipeline itself is
language-agnostic where the tools allow (yt-dlp captions, MMS forced alignment).*

## Что умеет

- **Аудиорежим**: текст прокручивается за чтецом, подсветка предложения и слова, клик по
  предложению перематывает, клавиши для навигации, повтор предложения, скорость.
- **Режим книги**: разворот из двух страниц без аудио, листание клавишами и кликом по краям. Книги без аудио открываются сразу в нём. Позиция хранится по предложению, поэтому
  переключение между режимами и смена шрифта места не теряют.
- **Фокус и глаза**: спринт с паузой на границе предложения и перерывом, приглушение текста
  вокруг абзаца или предложения, гашение панелей во время чтения, пауза при уходе из вкладки,
  пять тем включая тёплую ночную, встроенные шрифты для длинного чтения, насыщенность текста.
- **Библиотека**: полки «Читаю сейчас» и «Остальные», сортировка по последнему открытию,
  ярлык «прочитано», обложки и иллюстрации из книги, строка «где остановился» в шапке.
- **Хочу прочитать**: сохраняешь название, текст ищется по библиотекам (fantasy-worlds,
  Flibusta, Coollib) и загружается, если нашлась ровно эта книга целиком; тома склеиваются.
  Аудио выбираешь сам и добавляешь к книге кнопкой «＋ аудио».
- **Форматы**: страницы fantasy-worlds, любая HTML-страница, FB2, FB2.zip, EPUB, TXT; аудио с
  YouTube или локальные файлы, несколько частей подряд склеиваются в одну дорожку.
- Позиция, режим, настройки и статистика хранятся на сервере в `books/`, поэтому одинаковы в
  любом браузере и переживают перезапуск.

## Установка на macOS

```bash
brew install python@3.12 ffmpeg yt-dlp node
git clone git@github.com:diasbro/readsync.git && cd readsync
make setup          # виртуальное окружение и зависимости (около 600 MB: faster-whisper, onnxruntime)
make serve          # http://127.0.0.1:8765
```

`make serve` запускает `.venv/bin/python serve.py` (нужен Python 3.11+, системный
`/usr/bin/python3` не подойдёт). Порт и адрес: `serve.py --host 0.0.0.0 --port 8765`.
Node нужен только для `make lint`.

## Добавить книгу

Из браузера: на главной «Хочу прочитать» (название, всё остальное найдётся) или «Добавить
вручную» внизу (ссылки или файлы текста и аудио, тома и части по одной ссылке в строке).
Прогресс загрузки показывается на той же странице.

Из терминала:

```bash
.venv/bin/python pipeline/add_book.py my-book \
    --text "https://reader.fantasy-worlds.org/book/NNNNN/read.html" \
    --audio "https://www.youtube.com/watch?v=..." --narrator "Имя чтеца"
```

- `--text`: страница fantasy-worlds, любая HTML-страница, FB2, FB2.zip, EPUB или TXT (файл или
  прямая ссылка). Повторить для томов, они склеятся по порядку.
- `--audio`: ссылка YouTube (качается звук и авто-субтитры) или локальный файл (mp3, m4a, m4b).
  Повторить для частей. Только `--audio` с существующим slug добавляет звук к книге без аудио.
- `--title`, `--author`, `--narrator`, `--lang ru`, `--whisper-model small`.
- `--no-align` пропускает точный проход MMS: подсветка идёт по субтитрам, что уже точно до
  ~0.1 с. Точный проход можно запустить позже: `make align slug=my-book` (около 15 минут на
  час аудио на efficiency-ядрах; `pipeline/align.py --fast` берёт все ядра).
- Без субтитров аудио транскрибируется faster-whisper (медленно, но один раз).

## Как это работает

1. `extract_text.py` (fantasy-worlds и любой HTML), `extract_fb2.py`, `extract_epub.py`,
   `extract_txt.py`: текст в блоки (абзацы, заголовки, стихи, иллюстрации) и предложения;
   `merge_books.py` склеивает тома.
2. `anchors.py`: слова книги сопоставляются со словами субтитров (diff по окнам), получаются
   якоря «слово → секунда». `transcribe.py`: субтитры из faster-whisper, если своих нет.
3. `timing_from_anchors.py`: интерполяция для слов без якоря → `timing.json`.
4. `align.py`: окна по ~2 минуты между якорями через MMS forced aligner (ONNX, CPU), уточняются
   границы слов.
5. `serve.py`: статика, HTTP Range для аудио, состояние чтения, поиск по библиотекам, запуск
   `add_book.py` фоновыми задачами.
6. `reader/`: статичная страница без зависимостей: бинарный поиск слова по времени, подсветка,
   автоскролл, режим книги на CSS-колонках.

Данные книг лежат в `books/<slug>/` и в git не попадают: `book.toml` (метаданные), `book.json`,
`timing.json`, `audio.m4a`, `images/`, `state.json` (позиция, режим, статистика). Общие
настройки в `books/settings.json`, список желаний в `books/wishlist.json`.

## Клавиши

Аудио: пробел играть/пауза · ← → предложения · Shift+← → ±10 с · r повторить предложение ·
[ ] скорость · f приглушение · t оглавление · a вернуться к текущему месту · m режим книги.
Книга: ← → пробел листать · Shift+пробел назад · PageUp/PageDown · Home/End · t оглавление ·
m обратно к аудио.

## Разработка

`make test` (pytest), `make lint` (ruff, `node --check`), `make fmt`, `make fonts` (пересобрать
`reader/fonts/` из Google Fonts). CI на GitHub Actions делает то же. Правила для агентов и
соглашения по коду в `CLAUDE.md`, решение по выравниванию в `docs/adr/`.
