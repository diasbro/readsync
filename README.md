# readsync

Синхронное чтение: текст книги в браузере с подсветкой предложения и слова,
которые сейчас звучат в аудиокниге. Immersion reading для тренировки фокуса.

## Запуск

```bash
python3 serve.py            # http://127.0.0.1:8765
```

Библиотека на главной, книга по `?book=<slug>`. Позиция, настройки и статистика
хранятся на сервере (`books/settings.json` общие настройки, `books/<slug>/state.json` позиция,
режим и статистика книги), поэтому одинаковы в любом браузере и
переживают перезапуск; localStorage только кэш.

## Добавить книгу

Проще всего из браузера: на главной «Добавить книгу», ссылка или файл текста (fantasy-worlds,
FB2, HTML), при желании аудио (ссылка YouTube или файл), прогресс показывается там же.
Книга без аудио открывается в режиме книги. Из терминала:

```bash
python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python pipeline/add_book.py my-book \
    --text "https://reader.fantasy-worlds.org/book/NNNNN/read.html" \
    --audio "https://www.youtube.com/watch?v=..." \
    --narrator "Имя чтеца"
```

- `--text`: страница читалки fantasy-worlds или файл `.fb2` / `.fb2.zip`.
- `--audio`: ссылка YouTube (качается звук и авто-субтитры) или локальный файл (mp3, m4a, m4b).
- Без субтитров аудио транскрибируется faster-whisper (медленно, но один раз).
- `--no-align` пропускает точный проход MMS (по умолчанию он идёт на efficiency-ядрах с низким приоритетом, ~15 мин на час аудио; `--fast` = все ядра, ~7 мин на час, ноутбук греется);
  без него подсветка идёт по субтитрам, что уже точно до ~0.1 с.

Требуются `ffmpeg` и `yt-dlp` (brew).

## Как это работает

1. `extract_text.py` / `extract_fb2.py` — текст в блоки (абзацы, заголовки, стихи) и предложения.
2. `anchors.py` — слова книги сопоставляются со словами субтитров (diff по окнам), выходят якоря «слово → секунда».
3. `timing_from_anchors.py` — интерполяция для слов без якоря → `timing.json`.
4. `align.py` — окна по ~2 минуты между якорями прогоняются через MMS forced aligner (ONNX, CPU), уточняются границы слов.
5. `reader/` — статичная страница: бинарный поиск слова по времени, подсветка, автоскролл, оглавление, режим фокуса, спринт-таймер, статистика.

## Режимы чтения

- **Аудио**: текст прокручивается за чтецом, подсветка предложения и слова.
- **Книга** (кнопка 📖 или клавиша `m`): разворот из двух страниц без аудио, листание клавишами
  ← →, пробелом, колесом или кликом по краям; на узком окне одна страница. Позиция запоминается
  по предложению, поэтому при смене шрифта или окна место не теряется, а возврат к аудио
  перематывает на то же предложение. Книги без аудио всегда в этом режиме.

## Фокус и глаза

- Спринт (10/15/25/45 мин): пауза наступает на границе предложения, потом перерыв 5 мин с мягким сигналом.
- Во время чтения панели гаснут через 4 с без движения мыши; уход из вкладки ставит паузу (обе опции отключаются).
- Темы: как в системе, светлая, сепия, тёмная, ночная тёплая (меньше синего). Нативные контролы следуют теме через `color-scheme`.
- Подсветка слова заливкой или мягким подчёркиванием; приглушение остального текста.
- Шрифты встроены (OFL, кириллица, `reader/fonts/`): текст Literata (по умолчанию), PT Serif, Merriweather,
  системные Iowan Old Style / Charter / Georgia, без засечек Inter / Golos Text / IBM Plex Sans;
  интерфейс Inter (по умолчанию), Golos Text, IBM Plex Sans, системный. Насыщенность текста регулируется.
- Приглушение: всё кроме абзаца или всё кроме предложения (клавиша f переключает).
- После паузы дольше 8 с воспроизведение начинается с начала предложения (отключается).
- Сдвиг подсветки ±600 мс, если синхронизация кажется ранней или поздней.
- Статистика: сегодня, всего, серия дней, столбики за 7 дней.

## Клавиши

пробел — играть/пауза · ← → — предложения · Shift+← → — ±10 с · r — повторить предложение ·
[ ] — скорость · f — фокус · t — оглавление · a — вернуться к текущему месту · Esc — закрыть панели
